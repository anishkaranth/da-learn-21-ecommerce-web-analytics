# data/

- `raw/full_flatten_data.csv` is a **deterministic sample** of the real raw export (12,466 rows incl. header-repeat lines, 5,529,225 B), built by `scripts/make_sample.py` from the full file. The rule takes all events of every 1000th `user_pseudo_id` in sorted order (271 users), plus all events of every 80th purchasing user in sorted order (51 buyers, so the sample contains real transactions), plus the 31 repeated header lines found inside the export (so the cleaning rule that drops them is exercised). That gives 322 users. Same 60 columns and header, rows in original order. `python run_pipeline.py --source sample` runs the whole pipeline on it (28/28 assertions pass) and writes `results/sample/`.
- `raw_full/` (git-ignored) holds the full 1.84 GB file, written by `python scripts/download_full_data.py` (SHA-256 checked).
- `clean/star/` holds the cleaned star-schema exports from the full run (the same files as `powerbi/data/`): full `dim_*`, full `fact_transaction` (4,887), the full `agg_daily_device_channel` (1,924 rows), and a 1-in-20 `fact_session_sample` (18,006 of 360,129 sessions, `session_key % 20 = 0`).
